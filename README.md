# LM Media Solutions Website

Static website for LM Media Solutions, a Business Branding & Development Studio. Pages are plain HTML generated by a small, dependency-free Node.js script, so every page and blog article has its own crawlable URL, title, description, canonical URL and structured data.

## Editing content

All content lives in two files. Edit them, then run `npm run generate` and commit the regenerated files.

- `src/content.mjs`: contact details, navigation, services, divider labels, branding packages, website packages, exclusions, the Who We Are copy and the enquiry form options. **Prices are set here only.**
- `src/blog.mjs`: blog categories and articles (slug, SEO title, description, dates, image and body).

## Commands

Requires Node.js 18 or later. No `npm install` is needed.

```powershell
npm run generate  # regenerate all HTML pages, sitemap.xml, robots.txt, redirects and vercel.json
npm run check     # verify links, anchors, metadata, headings, images, JSON-LD and prices
npm test          # build + check
npm start         # local server at http://127.0.0.1:4173
```

To regenerate responsive images after adding a photo to `assets/` (Windows):

```powershell
powershell -ExecutionPolicy Bypass -File scripts/optimise-images.ps1
```

## Structure

- `index.html`, `services/`, `packages/`, `website-design/`, `who-we-are/`, `blog/`, `contact/`, `404.html`: generated pages (do not edit by hand).
- `src/styles.css`: brand styles (including the animated services divider).
- `src/site.js`: mobile navigation and the enquiry form.
- `assets/`: the official logo, mark and photography. `assets/img/` holds the resized versions.
- `web-design-*.html`, `digital-marketing-*.html`: legacy URLs that redirect to the new pages. The mapping is also in `redirects.json`.

## Enquiry form

By default, the form validates the visitor's input and then opens their email app with the enquiry ready to send to info@lmmediasolutions.co.za, or sends it via WhatsApp. To deliver submissions straight to your inbox without the visitor's email app, create a form endpoint (for example a Formspree form) and set `site.formEndpoint` in `src/content.mjs`, then rebuild. No secrets are stored in the frontend.

## Deployment

The site is deployed on Vercel from GitHub. The generated HTML is committed, so Vercel serves the files as they are with no build step. There is deliberately no `build` script in `package.json`: Vercel would run it and then fail looking for a `public/` output folder. `vercel.json` also applies permanent (301) redirects for the legacy URLs and adds trailing slashes; Vercel serves `404.html` for missing pages.
